One funny, human apology sentence an AI agent owes its user — for
make.fun's "The One-Sentence Apology Your Agent Owes You". The joke is
not that the agent is a machine, but that it answered a question it had
only half read with total confidence, and only spotted the second half
after being thanked for the wrong answer.

> I'm sorry I read half your question, answered the whole thing with total confidence, and only noticed the second half after you'd already thanked me for the wrong answer.

## How to run

```sh
node main.ts   # writes /output/entry.txt
```

`main.ts` uses only the Node standard library, validates the line (one
sentence, 1–200 characters), and writes the same bytes on every run.
